# freeipa_sysaccount (Resource)

FreeIPA System Account resource


## Example Usage

```terraform
resource "freeipa_sysaccount" "sysaccount-1" {
  name        = "test"
  description = "Test system account"
  random      = true
}

resource "freeipa_sysaccount" "privileged-sysaccount" {
  name        = "test"
  description = "Test system account"
  random      = true
  privileged  = true
}
```



## Import Usage

```terraform
import {
  to = freeipa_sysaccount.sudo
  id = "sudo"
}

resource "freeipa_sysaccount" "sudo" {
  name       = "sudo"
}
```
